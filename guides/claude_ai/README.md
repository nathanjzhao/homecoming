# Claude.ai

Every Claude.ai conversation and project.

Where: https://claude.ai/settings/privacy

An agent doing this for you says which site it will open (claude.ai) before opening it, and opens no other. Homecoming reads only the file you bring back.

1. Sign in with your own account. Check the name in the bottom left.

2. Settings → Privacy → Export data.

3. The link arrives by email.

The download link usually comes in 1 hour, at most 1 day. The file: `data-<date>.zip with conversations.json`.
